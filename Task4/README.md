# Financial Organisation — Cyber Security Dashboard
## Task 4 | Data Science for Cyber Security

A real-time Plotly Dash security monitoring dashboard covering four domains:
Network Traffic, Endpoints, Data Backups, and Staff Readiness.

---

## Quick Start

### 1. Install Requirements

```bash
pip install -r Task4/requirements.txt
```

### 2. Generate Dummy Data

Run the data generation script **once** before launching the dashboard.
It creates four CSV files in the `Task4/` directory.

```bash
python Task4/generate_data.py
```

Expected output:
```
[generate_data] Saved 10 rows → .../Task4/network_traffic.csv
[generate_data] Saved 10 rows → .../Task4/endpoints.csv
[generate_data] Saved 10 rows → .../Task4/backups.csv
[generate_data] Saved 10 rows → .../Task4/staff_readiness.csv

[generate_data] All data files generated successfully.
```

### 3. Run the Dashboard

```bash
python Task4/dashboard.py
```

Then open your browser at: **http://127.0.0.1:8050**

## Dashboard Sections & Charts

### KPI Summary Cards (top of page)
Four headline metrics refreshed automatically every 30 seconds:
| Card | Metric | Colour Coding |
|------|--------|---------------|
| Total Anomalies Detected | Count of network anomaly flags | Red ≥1, Green = 0 |
| Endpoints with Issues | Count of endpoints with active_issues > 0 | Red ≥5, Amber >0, Green = 0 |
| Avg Backup Coverage | Mean coverage_pct across all backup jobs | Red <60%, Amber 60–80%, Green ≥80% |
| Staff High Risk Count | Count of employees with risk_profile = High | Red ≥3, Amber >0, Green = 0 |

---

### Section 1 — Network Traffic

**Chart 1: Network Throughput Over Time** *(Interactive)*
- Line chart plotting `throughput_mbps` against `timestamp`.
- **Interaction:** Use the **Filter by Protocol** dropdown above the chart to isolate a single protocol (TCP, UDP, HTTPS, etc.) or view all.
- Anomalous sessions are overlaid as large red ✕ markers.

**Chart 2: Global Network Traffic Sources** *(Geo-spatial)*
- World map with each network session plotted at its source coordinates (`src_lat`, `src_lon`).
- Point **colour**: green = normal session, red = anomaly.
- Point **size**: proportional to `throughput_mbps`.
- **Hover tooltip** shows: source IP, protocol, throughput (Mbps), anomaly status.

---

### Section 2 — Endpoints

**Chart 3: Endpoint Security Status Overview**
- Stacked bar chart with one stack per hostname.
- Three layers per bar: **Firewall**, **Antivirus**, **Disk Encryption**.
- Colour coding: green = secure/active/updated, amber = outdated, red = inactive/missing/disabled.
- Hover over each segment to see the exact status value.

---

### Section 3 — Data Backups

**Chart 4a: Average Backup Coverage** (Gauge)
- Plotly gauge showing mean `coverage_pct` across all backup jobs.
- Colour zones: 0–60% red (critical), 60–80% amber (warning), 80–100% green (compliant).
- Delta indicator shows deviation from the 80% target threshold.

**Chart 4b: Backup Validation Results** (Pie)
- Donut pie chart showing proportion of Pass vs Fail `validation_result` values.
- Green = Pass, Red = Fail.

---

### Section 4 — Staff Readiness

**Chart 5: Staff Risk Profile by Department**
- Horizontal grouped bar chart.
- Each department shows three bars: Low (green), Medium (amber), High (red) risk staff counts.
- Enables rapid identification of departments with elevated human-risk exposure.

**Chart 6: Training Compliance vs Risk Profile** *(Interactive)*
- Scatter plot: X = `days_since_training`, Y = `training_completion_pct`.
- Point **colour** = risk profile (green/amber/red).
- Point **size** = number of pending trainings (larger = more outstanding modules).
- **Hover tooltip** shows: employee ID, department, job role, last phishing simulation result.
- **Interaction:** Use the **range slider** below the x-axis to filter the view by days since last training.

## Auto-Refresh

The dashboard uses `dcc.Interval` to reload all four CSV files from disk every **30 seconds**.
A console message is printed each time data is reloaded:

```
[dashboard] Data reloaded at 14:32:15
```

To simulate live data updates, modify or regenerate the CSV files while the dashboard is running.
